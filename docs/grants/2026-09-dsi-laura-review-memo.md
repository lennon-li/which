## Current project framing

**Title:** Measure Before You Share: Calibration, Uncertainty, and Dual-Gate Safety for AI Access to Medical and Public-Health Data

**Request:** CAD $75,000 in Claude API credits over 12 months.

**Core scientific question:** Can calibrated statistical and semantic evidence determine whether an original, transformed, synthetic, or summarized representation of medical/public-health data is appropriate to expose to a cloud AI agent for a specific task?

**Main contributions:**
- privacy-aware AI data-access decisions rather than generic PII detection;
- interpretable statistical + semantic typed-decision models;
- calibration, uncertainty, abstention, correlated-error and harm-weighted evaluation;
- reusable training/adaptation and classifier-evaluation infrastructure in Which;
- privacy implementation in DataGangeR;
- 3–5 supervised Biostatistics/data-science trainees;
- open benchmark, open-source software, methods manuscript, and optional partner pilot;
- phased stop/go design so failure of a later modelling stage does not cause project failure.
