## AI, data safety and open-source contributions

- **DataGangeR (CRAN/GitHub)** — Human-gated privacy protocol for agent-assisted prototyping. Produces synthetic stand-ins and reproducible generation recipes so coding agents can work without direct access to original records; designed around data minimization and no-network defaults.
- **Which (in development)** — Engine-neutral framework for typed AI decisions, probability normalization, calibration, abstention, uncertainty, cross-model comparison, regression release gates, and human-governed labelled-data/model-improvement workflows; current work includes Laya/Jev evaluation.
- **aiR** — Deployed AI-assisted companion for R statistical analysis with agent-guided exploration, modelling and interpretation while preserving analyst control over decisions and execution.
- **Rock** — Containerized R/data-science environment for Claude Code, Codex and Gemini CLI; isolates agents from host files and credentials by default and preserves human review before release.
- **insideR / IPD** — Transparency and deliberation tools for tracing/replaying R calls and for independent multi-agent review with preserved disagreement, uncertainty, and explicit human decision authority.
- **ONgeoR / OPCC / courieR** — Open-source R packages for Ontario public-health geography, source-qualified postal-code correspondence, and reproducible R package migration; developed with AI coding agents under human direction and review.

## Current research

- **Privacy-aware AI data access** — calibrated statistical and semantic decisions about the minimum appropriate representation of medical/public-health data to expose to AI, with abstention, dual-gate safety, harm-weighted evaluation, and human review.
- **Typed-decision model evaluation** — converting free-form AI judgment into standardized classifications and probabilities that can be scored, calibrated, stress-tested, compared across models, and monitored over time.
- **PAGe infectious-disease forecasting** — phase-aligned influenza forecasting with ignition detection, epidemic-curve alignment/peak tracking, and short-horizon probabilistic forecasting.
- **Human-gated scientific agents** — multi-agent research/software workflows emphasizing delegation, independent verification, reproducibility, explicit uncertainty, controlled data boundaries, and accountable release decisions.
